📄 Artigo Científico: A Jornada da Modernização
📌 Sobre a Publicação
Este repositório contém a documentação e o texto integral do artigo científico "A Jornada da Modernização: A Transição Estratégica de Planilhas para Aplicações Web Escaláveis em Pequenos Negócios".

O trabalho foi desenvolvido com o objetivo de investigar e documentar os impactos técnicos e operacionais na substituição de ferramentas legadas de escritório por arquiteturas web modernas. A pesquisa aborda como a transformação digital, focada em engenharia de software e banco de dados, atua como pilar de escalabilidade para micro e pequenas empresas.

🎯 Estudo de Caso Prático
A análise teórica do artigo é embasada em um cenário real de transição tecnológica comercial. O estudo documenta a substituição de um sistema de controle fundado em planilhas e macros para uma aplicação web centralizada, desenvolvida para gerir o fluxo de estoque de uma distribuidora local de temperos.

O grande desafio resolvido e documentado no artigo é o fracionamento de matéria-prima: a lógica de processamento necessária para registrar a entrada de insumos em grande volume (sacas de 5kg e 10kg) e a sua respectiva conversão automatizada em centenas de pequenas porções (embalagens de 10g e 20g) para revenda, sem a perda de integridade de dados ou desvios matemáticos de inventário.

🛠️ Tecnologias e Arquitetura Discutidas
O trabalho fundamenta sua proposta de modernização no seguinte ecossistema:

Banco de Dados: Modelagem relacional estrita implementada em MySQL, garantindo propriedades ACID e eliminando redundâncias típicas de arquivos estáticos.

Backend & Lógica de Negócio: Estruturação do servidor utilizando Python aliado ao microframework Flask, isolando as regras de fracionamento de estoque e preparando a base para automações.

Arquitetura: Adoção do modelo Cliente-Servidor e preparação de endpoints padronizados.
